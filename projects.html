Selected work

  1. HST-StudioA delta-aware sparse linear algebra runtime, and the tooling around it.
  2. Not HotdogHot dog or not hot dog: a 136,417-parameter int8 CNN with hand-written JavaScript kernels, zero dependencies, and bit-exact parity against a NumPy reference.
  3. paper-digestCloudflare Worker that ranks each day's new arXiv papers against plain-English interests, with a keyword fallback so the API never breaks.
  4. ResilientStatically-typed compiled language for safety-critical embedded systems. Z3-verified contracts, no_std runtime, ships to Cortex-M and RISC-V.
  5. TLA+TLA+ modeling and verification work, including interactive examples, research tools, and generated specifications.
  6. tlakitPython and notebook client for the TLA+ toolchain. Drives SANY, TLC, and TLAPS from a cell without reimplementing TLA+ semantics.
