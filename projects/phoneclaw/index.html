PhoneClaw

A Mac bridge and old-iPhone client for text-based agent access.

PhoneClaw uses a Mac daemon to read incoming iMessage and SMS activity, route approved messages to agent backends, and send replies through Messages.app. A companion iOS app runs on an old iPhone as a kiosk client and status surface.

The bridge is the component that sends messages. The phone communicates with the bridge over HTTP and WebSocket after pairing; it does not send iMessages directly because iOS does not expose that API.

Constraints

The tested baseline is an iPhone 7 running iOS 15.8.5. The Mac process needs Full Disk Access to read the Messages database, and the iOS app must remain in the foreground for reliable delivery. The default configuration uses an explicit sender allowlist.
