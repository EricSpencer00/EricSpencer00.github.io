Hermes Ops

Operations scripts and configuration for the Hermes agent.

Hermes Ops contains the scripts and configuration used to run an agent gateway, notify when coding jobs finish, dispatch work in isolated worktrees, and report status to Discord. The repository also tracks the agent identity and the rules used by the dispatcher.

The project separates operational configuration from credentials. Tokens and local environment files stay on the machines that run Hermes; they are not part of the repository.

Current state

The repository includes live notification hooks, guarded agent spawning, watchdog and usage-pacing scripts, and migration notes for running Hermes on a Mac mini. Some controls remain notify-only until they have been calibrated against live agent sessions.
