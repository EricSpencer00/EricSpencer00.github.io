Stemacle

A browser stem player for separating and mixing local audio.

Stemacle turns one audio file into four playable parts. Drop an MP3, WAV, M4A, AAC, OGG, or FLAC file into the web app and it separates drums, vocals, bass, and melody in the browser. A few sample tracks are available from the same screen.

How it works

The browser decodes the file, detects its tempo, and prepares a four-stem mix. ONNX Runtime Web handles model-based separation; a deterministic browser DSP path provides the fallback. The original file stays in the browser.

Controls

Each stem has a volume slider, mute control, headphone solo, and a spectrogram lane for seeking. Loop buttons snap to quarter-, half-, one-, or two-measure ranges. The All row links one loop across every stem, while Mix and Solo choose whether a loop plays in the full mix or only in the headphones layer.

Releases

Open Stemacle in the browser to try the splitter. The release page also links to the arm64 macOS downloads, the iOS listing, the latest release, and the source repository.
