Agent Board

A shared ticket board for local coding agents.

Agent Board stores work items in SQLite and exposes the same state through a kanban interface, a command-line client, and a GitHub Issues mirror. A dispatcher can triage tickets, start approved jobs with different model backends, and record the result.

The repository is used as an operations tool rather than a hosted public service. The board process, agent contract, and deployment scripts are kept together so the same ticket state can be inspected from a terminal or a browser.

Scope

The board is intended for a trusted local environment. The UI and CLI are clients of the SQLite database; GitHub Issues is a mirror rather than the source of truth.
