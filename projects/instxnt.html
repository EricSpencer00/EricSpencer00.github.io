instxnt.xyz

A dashboard and storefront system for creating AI-powered online stores.

live site

instxnt.xyz combines a storefront dashboard with an API worker. The dashboard is a Next.js application deployed to Cloudflare through OpenNext. It includes Google sign-in, store management, image upload, generation status, settings, custom-domain configuration, and billing screens.

The project is structured as a private product repository. The UI calls the API through an environment-configured endpoint, and production deployment uses a Cloudflare Worker rather than the older Pages workflow.

Current state

The repository is an active product codebase rather than a generic demo. Its public surface is the storefront and dashboard; implementation details and deployment configuration remain private.
