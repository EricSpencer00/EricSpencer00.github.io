AI SEO Queries

Chrome extension that shows the exact web searches ChatGPT, Claude, and Perplexity run for your prompts.

Version 2.0.1 · repo: EricSpencer00/aeo-extension

Install from Chrome Web Store

GitHub Repo · Privacy Policy

AI SEO Queries shows the search queries an AI assistant uses while preparing an answer. Seeing those queries makes it easier to study the topics, wording, and sources that shape an AI-generated result.

How it works

Ask a question in ChatGPT, Claude, or Perplexity, then open the Chrome side panel. The extension displays the search queries associated with the response, including reformulations and search operators when they are available.

Verification

The extension has been tested with real prompts on ChatGPT, Claude, and Perplexity. Gemini and Copilot support is available on a best-effort basis.

Privacy and permissions

Captured information stays in Chrome on your device. The extension operates on the supported AI sites and does not upload captured queries. Read the full privacy policy for collection, storage, retention, and permissions details.

Output

  • A timeline pairing prompts with the queries they triggered
  • Queries ranked by frequency
  • Filtering by text and assistant
  • CSV export of timestamp, source, prompt, and query
  • One-click copy of a query or the visible set

Status

Version 2.0.1 is available in the Chrome Web Store. Install it from the link above, open the side panel, and ask an AI assistant a question that needs current information.
