# Portfolio fonts

These are the unchanged Latin WOFF2 subsets served by Google Fonts on 2026-09-22.
Both families are redistributed under the included SIL Open Font License files.

- Plus Jakarta Sans, variable weights 300–700: https://fonts.gstatic.com/s/plusjakartasans/v12/LDIoaomQNQcsA88c7O9yZ4KMCoOg4Ko20yw.woff2
- IBM Plex Mono, weight 400: https://fonts.gstatic.com/s/ibmplexmono/v20/-F63fjptAgt5VM-kVkqdyU8n1i8q1w.woff2
- IBM Plex Mono, weight 500: https://fonts.gstatic.com/s/ibmplexmono/v20/-F6qfjptAgt5VM-kVkqdyU8n3twJwlBFgg.woff2

License sources:

- https://github.com/google/fonts/blob/main/ofl/plusjakartasans/OFL.txt
- https://github.com/google/fonts/blob/main/ofl/ibmplexmono/OFL.txt

The primary face is preloaded. `font-display: optional` keeps a slow font download
from changing the layout after text has appeared; system fallbacks also cover
characters outside the Latin subset. The shared stylesheet is `/assets/css/fonts.css`.
